HELP

Common Playback Problems

Some video files may behave differently depending on their codec, resolution and device hardware.

Video Does Not Play

Check whether the file is complete and whether its audio and video codecs are compatible with the application and Android device. Try another known-compatible video file to compare playback.

No Audio

Check the device volume and make sure the video actually contains an audio track. Some files use audio codecs that may not be available on every Android device.

Subtitle Not Showing

Make sure the subtitle file is compatible and correctly selected. When using an external subtitle file, check that the file is readable and matches the video.

Playback Is Not Smooth

High-resolution or high-bitrate videos can require more processing power. Try a lower-resolution copy of the video or check the device's available storage and background activity.
